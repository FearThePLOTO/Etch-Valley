# Etch Valley

Retro harvest sketch pad. Hold left click and drag to draw.

Pencil (pick any color) - Rainbow - Eraser - Clear - 4 to 100 grid.

Play it here: https://feartheploto.github.io/Etch-Valley/

Built with HTML, CSS (Flexbox only) and JS for The Odin Project.
